# Zachariah Emmanuel — Academic Website

This folder is ready for GitHub Pages.

## Files

- `index.html` — main website
- `style.css` — site design
- `cv.pdf` — replace this placeholder with your current CV using exactly this filename
- `assets/profile-placeholder.svg` — placeholder image
- `papers/job-market-paper.pdf` — replace placeholder with your actual job market paper

## Add your professional photo

1. Put your headshot inside the `assets` folder.
2. Rename it `profile.jpg`.
3. In `index.html`, find:

   `assets/profile-placeholder.svg`

4. Replace it with:

   `assets/profile.jpg`

## Add your CV

Place your CV PDF in the main folder and name it:

`cv.pdf`

## Add your Job Market Paper

Place the paper in the `papers` folder and name it:

`job-market-paper.pdf`

## Publish with GitHub Pages

If your GitHub username is `USERNAME`:

1. Create a public repository named `USERNAME.github.io`.
2. Upload the contents of this folder to the repository.
3. Commit the files to the `main` branch.
4. Open repository **Settings**.
5. Click **Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select **main** and **/(root)**.
8. Click **Save**.

Your website address will be:

`https://USERNAME.github.io`

## Customize
